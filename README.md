# Noticias — News Application

A news aggregation app built with **Angular** that fetches and displays articles from external news APIs.

## Tech Stack

| Layer | Technologies |
|-------|-------------|
| Frontend | Angular, TypeScript, Bootstrap |
| Data | News API / REST |
| Styling | CSS3, Angular Material |

## Features

- Browse top headlines by category
- Search articles by keyword
- Article detail view
- Category filtering
- Responsive mobile-first design
